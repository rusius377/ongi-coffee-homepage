# 온기커피 홈페이지 — 수정 가이드

> 포트폴리오용으로 만든 **가상의 카페** 홈페이지예요. HTML · CSS · JavaScript만 써서 따로 설치할 프로그램이 없어요.
> 도구 2개(`사진 줄이기.bat`, `주소 바꾸기.bat`)는 윈도우에서 더블클릭하면 실행돼요.

---

## 1. 브라우저로 보기

- **가장 쉬운 방법:** `index.html` 파일을 더블클릭하면 기본 브라우저에서 열려요.
- **휴대폰 화면으로 보기 (크롬·엣지)**
  1. `F12`를 눌러 개발자 도구를 열어요.
  2. `Ctrl + Shift + M`을 누르면 휴대폰 화면으로 바뀌어요.
  3. 위쪽 기기 목록에서 iPhone, Galaxy 등을 골라요. 기기를 가로로 눕혀 보는 버튼도 있어요.
- 파일을 고친 뒤에는 `F5`를 누르면 바로 반영돼요. 바뀌지 않으면 `Ctrl + F5`를 눌러 보세요.

> 글꼴(Pretendard)과 지도는 인터넷에서 불러와요. 인터넷이 끊겨 있으면 글꼴이 기본 글꼴로 보이고 지도가 비어 보여요.

## 2. 폴더 구조

```
cafe-homepage/
├─ index.html          ← 글자·메뉴·가격·링크 수정은 여기서
├─ css/style.css       ← 색상·디자인 (맨 위 색상 값만 바꾸면 전체에 적용)
├─ js/main.js          ← 영업시간 설정, 메뉴 열기·사진 크게 보기 같은 기능
├─ images/             ← 사진 (같은 이름으로 덮어쓰면 교체 끝)
├─ favicon.ico         ← 브라우저 탭 아이콘
├─ robots.txt          ← 검색엔진 안내 파일 (건드릴 일 거의 없음)
├─ sitemap.xml         ← 검색엔진에 알려 주는 페이지 목록
├─ 사진 줄이기.bat     ← 더블클릭: 사진을 알맞은 크기로 정리
├─ 주소 바꾸기.bat     ← 더블클릭: 배포 후 사이트 주소를 한 번에 변경
├─ tools/              ← 위 두 도구의 실제 내용 (건드리지 않아도 돼요)
├─ .vercelignore       ← 배포할 때 빼는 파일 목록 (도구·백업·이 안내서)
└─ README.md           ← 지금 보고 있는 안내서
```

## 3. 파일 고치는 법

- 메모장으로도 고칠 수 있지만, 무료 프로그램 **VS Code**를 쓰면 훨씬 편해요.
- `index.html` 안에서 **✏️ 표시가 있는 안내 문구** 바로 아래가 고치면 되는 부분이에요.
- `Ctrl + F`로 바꾸고 싶은 글자(예: `6,000원`)를 찾아서 바로 고치면 돼요.
- 저장할 때 인코딩은 **UTF-8**을 유지해 주세요. 다른 형식으로 저장하면 한글이 깨져요. VS Code와 최신 메모장은 기본값이 UTF-8이에요.
- `<`, `>`, `"` 기호는 지우지 않도록 조심하세요. 그 사이에 있는 **글자만** 바꾸면 안전해요.

## 4. 사진 바꾸기

### 순서
1. 새 사진을 **아래 표의 이름**으로 `images` 폴더에 넣어요. 같은 이름의 파일이 있으면 덮어쓰면 돼요.
2. **`사진 줄이기.bat`을 더블클릭해요.** 사진이 홈페이지에 알맞게 정리돼요.
3. 브라우저에서 `F5`를 눌러 확인해요.

| 사진 | 파일 이름 | 권장 크기 |
|---|---|---|
| 배너 (태블릿·PC) | `images/hero.jpg` | 1920×1080 가로형 |
| 배너 (휴대폰) | `images/hero-mobile.jpg` | 900×1200 세로형 — **안 넣어도 돼요** (아래 참고) |
| 소개 | `images/about.jpg` | 1200×900 |
| 메뉴 6장 | `images/menu/menu-01.jpg` ~ `menu-06.jpg` | 800×800 정사각형 |
| 갤러리 6장 | `images/gallery/gallery-01.jpg` ~ `gallery-06.jpg` | 1200×900 |
| 공유 미리보기 | `images/og-image.jpg` | 1200×630 (카카오톡 링크 공유 시 보이는 사진) |

### `사진 줄이기.bat`이 해 주는 일
- **너무 큰 사진**은 위 크기로 줄이고, 한 장에 500KB 이하로 압축해요. 휴대폰 원본(4~8MB)도 그대로 넣으면 돼요.
- **옆으로 누운 휴대폰 사진**은 바로 세워요.
- **사진 속 위치정보(GPS)를 지워요.** 휴대폰 사진에는 찍은 장소가 기록돼 있어서, 그대로 올리면 누구나 확인할 수 있어요.
- **PNG, `.jpeg`, 대문자 이름**(`MENU-01.JPG`)은 홈페이지가 쓰는 `menu-01.jpg` 형식으로 맞춰요. 배포 서버는 대문자와 소문자를 다른 이름으로 봐서, 이름이 조금만 달라도 사진이 안 나와요.
- **배너 `hero.jpg`를 바꾸면 휴대폰용 `hero-mobile.jpg`를 자동으로 만들어요.** 사진 가운데를 세로로 잘라서 만들어요.
  - 휴대폰에서 보이는 부분을 직접 고르고 싶으면 `hero-mobile.jpg`를 따로 넣으면 돼요. 직접 넣은 사진은 도구가 덮어쓰지 않아요.
  - 나중에 다시 자동으로 만들고 싶으면 `hero-mobile.jpg`를 지우고 도구를 실행하세요.
- **바꾸기 전 원본은 `_사진원본백업` 폴더에 날짜별로 보관돼요.** 이 폴더는 배포되지 않아요.
- 이미 알맞은 사진은 건드리지 않아요. 여러 번 실행해도 괜찮아요.
- 아이폰의 **HEIC 사진은 바꿀 수 없어요.** 도구가 `[주의]` 메시지로 알려 줘요. 아이폰에서 **설정 → 카메라 → 포맷 → '높은 호환성'**으로 바꾸고 찍으면 JPG로 저장돼요.

### 사진 설명 (alt)
`index.html`에서 사진 줄의 `alt="..."` 안에 있는 글자가 사진 설명이에요. 시각장애인용 화면 낭독기가 이 글을 읽어 주고, 갤러리에서 사진을 크게 볼 때도 설명으로 나와요. **사진을 바꾸면 설명도 사진 내용에 맞게 고쳐 주세요.**

### 저작권
직접 찍은 사진이 가장 안전해요. 무료 사진은 [Unsplash](https://unsplash.com), [Pexels](https://www.pexels.com)처럼 상업적으로 써도 되는 곳에서 받고, 사진마다 라이선스를 한 번씩 확인해 주세요.

## 5. 자주 하는 글자 수정

### 메뉴 이름·설명·가격
`index.html`에서 `✏️ 메뉴 1` ~ `✏️ 메뉴 6`을 찾아 글자를 바꾸면 돼요.

메뉴를 늘리고 싶다면 `<li class="menu-card ...">`부터 `</li>`까지를 통째로 복사해서 바로 아래에 붙여 넣으세요.

### 영업시간 — 아래 곳을 함께 바꿔 주세요
1. `index.html`의 `✏️ 영업시간` 표. 그리고 `Ctrl + F`로 `10:00`을 검색하면 나오는 곳들(예약 섹션 안내, 푸터, 맨 위 `description`)도 같이 바꿔요.
2. `js/main.js` 맨 위 `OPENING_HOURS`. "지금 영업 중" 자동 표시에 쓰여요.
   ```js
   open: '10:00',
   close: '21:00',
   closedDays: [1],   // 0=일, 1=월, 2=화 … 6=토
   ```
3. `index.html` 위쪽 `<script type="application/ld+json">` 안의 `opens`, `closes`, `dayOfWeek`. 검색엔진에 알려 주는 정보예요.
4. `images/og-image.jpg` 사진 안에도 영업시간 글자가 있어요. 공유 미리보기 사진을 새로 만들어 넣어 주세요.

### 전화번호
VS Code에서 `Ctrl + Shift + H`(폴더 전체 찾아 바꾸기)로 아래 두 가지를 **모두** 바꿔 주세요.
- `02-000-0000` → 화면에 보이는 번호
- `tel:020000000` → 누르면 전화가 걸리는 번호 (하이픈 없이 숫자만)

그리고 `ld+json` 안의 `"telephone"`도 같이 바꿔 주세요.

### 예약/문의 버튼 (카카오톡 → 구글 폼 · 예약 폼)
`index.html`에서 `✏️ 예약/문의 버튼 링크 바꾸는 법`을 찾으면 자세한 안내가 있어요. 요약하면 이래요.

| 바꾸고 싶은 것 | `href="#"`를 이렇게 |
|---|---|
| 카카오톡 채널 | `href="https://pf.kakao.com/_채널ID/chat"` |
| 구글 폼 | `href="https://forms.gle/폼주소"` (버튼 글자도 "온라인 예약하기"로) |
| 직접 만든 예약 페이지 | `href="reservation.html"` |

- 링크가 아직 `#`이면 버튼을 눌렀을 때 "준비 중" 안내가 떠요.
- 이름이나 연락처를 **직접 받는 예약 폼**을 만들면 개인정보보호법에 따라 **개인정보 처리방침** 페이지가 필요해요.

### 인스타그램
`index.html`에서 `✏️ 인스타그램`을 검색하면 **2곳**(방문 안내, 푸터)이 나와요. 두 곳의 `href="#"`를 `https://www.instagram.com/아이디/`로 바꾸세요.

### 지도 위치
`index.html` → `✏️ 지도 위치`. 지도 주소에서 `q=` 뒤의 글자가 검색어예요. 한글 주소를 그대로 써도 돼요.
```
https://maps.google.com/maps?q=서울 마포구 망원동 OO길 00&z=16&hl=ko&output=embed
```
아래 '네이버 지도에서 보기', '카카오맵에서 보기' 버튼 주소의 검색어도 같이 바꿔 주세요.

### 색상
`css/style.css` 맨 위 `:root { ... }` 안의 색상 코드만 바꾸면 사이트 전체에 적용돼요.

| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 크림 | `#FAF6F0` | 페이지 배경 |
| 라떼 | `#F2EADF` | 보조 배경 |
| 우드 브라운 | `#8B5E3C` | 버튼·가격·예약 섹션 |
| 로스트 브라운 | `#6F4A2F` | 마우스를 올린 버튼 |
| 에스프레소 | `#3B2A20` | 글자·푸터 |
| 모카 그레이 | `#746458` | 설명 글 |
| 캐러멜 | `#C8814A` | 장식선 (글자색으로는 쓰지 마세요) |
| 샌드 | `#E3D7C8` | 테두리 |

> 색을 바꾸면 글자가 잘 읽히는지 대비를 확인해 주세요. [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)에서 **4.5:1 이상**이면 통과예요.

### 제작자 이름 넣기 (포트폴리오용)
`index.html` 맨 아래쪽 `Designed &amp; built by 홍길동` 줄을 찾으세요. 그 줄 맨 앞의 `<!--`와 맨 뒤의 `-->`를 지우고 이름을 바꾸면 화면에 보여요.

## 6. 인터넷에 올리기 (Vercel)

### 처음 배포하기
1. 이 폴더를 **GitHub 저장소**에 올려요. [GitHub Desktop](https://desktop.github.com)을 쓰면 명령어 없이 올릴 수 있어요.
2. [vercel.com](https://vercel.com)에 GitHub 계정으로 가입해요.
3. **Add New → Project**에서 방금 올린 저장소를 고르고 **Import**를 눌러요.
4. Framework Preset은 **Other**로 두고 **Deploy**를 눌러요. 설정할 것은 없어요.
5. 배포가 끝나면 `https://프로젝트이름.vercel.app` 같은 주소가 생겨요.

> Vercel 화면의 버튼 이름은 업데이트로 조금 바뀔 수 있어요.
> 도구(`tools/`, `.bat`), 사진 백업, 이 안내서는 `.vercelignore` 덕분에 배포되지 않아요.

### 배포 후 사이트 주소를 한 번에 바꾸기 ⭐
지금은 사이트 주소가 임시 주소 `https://www.example.com`으로 들어가 있어요. 공유 미리보기, 검색엔진 등록, sitemap이 제대로 동작하려면 실제 주소로 바꿔야 해요.

1. **`주소 바꾸기.bat`을 더블클릭해요.**
2. Vercel 주소(예: `https://ongi-coffee.vercel.app`)를 입력하고 `Enter`를 눌러요.
3. `index.html`(6곳), `robots.txt`(1곳), `sitemap.xml`(1곳)이 한 번에 바뀌어요.
4. 바뀐 파일을 GitHub에 다시 올리면 Vercel이 자동으로 다시 배포해요.

- 나중에 직접 산 도메인(예: `https://www.ongicoffee.com`)으로 옮길 때도 같은 방법으로 한 번 더 실행하면 돼요.
- 주소 끝의 `/`는 붙여도 되고 안 붙여도 돼요. `https://`로 시작하지 않는 주소는 도구가 받지 않아요.
- **도구 없이 하려면:** VS Code에서 `Ctrl + Shift + H`를 누르고 찾을 말에 `https://www.example.com`, 바꿀 말에 새 주소를 넣은 뒤 **모두 바꾸기**를 누르면 돼요. 이 README 안의 예시 주소는 바뀌어도 상관없어요.

### 배포 후 할 일 (검색에 나오게 하기)
1. **네이버 서치어드바이저** ([searchadvisor.naver.com](https://searchadvisor.naver.com))
   1. 사이트 등록 → 소유 확인에서 **HTML 태그** 방식을 고르고, 받은 코드를 복사해요.
   2. `index.html` 위쪽의 `naver-site-verification` 줄에서 `content="..."`에 코드를 넣어요.
   3. 그 줄 맨 앞의 `<!--`와 맨 뒤의 `-->`를 지우고 다시 배포해요.
   4. 요청 → **사이트맵 제출**에 `sitemap.xml`을 입력해요.
2. **구글 서치콘솔** ([search.google.com/search-console](https://search.google.com/search-console))
   1. **URL 접두어** 방식으로 사이트를 등록하고, HTML 태그로 소유를 확인해요. `google-site-verification` 줄에 네이버와 같은 방법으로 넣으면 돼요.
   2. **Sitemaps** 메뉴에서 `sitemap.xml`을 제출해요.
3. **⚠️ 제일 중요한 것: 지도·플레이스 등록**
   네이버나 구글에서 "망원동 카페"를 검색하면 홈페이지보다 **지도·플레이스 영역**이 먼저 나와요. 거기에 나오려면 아래 두 곳에 가게를 등록하고, 등록 정보에 이 홈페이지 주소를 넣어 주세요.
   - **네이버 스마트플레이스** ([smartplace.naver.com](https://smartplace.naver.com))
   - **구글 비즈니스 프로필** ([business.google.com](https://business.google.com))
4. **카카오톡 미리보기가 예전 모습으로 나올 때**
   카카오는 미리보기를 한동안 저장해 둬요. [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 사이트 주소를 넣고 **초기화**를 누르면 새로 반영돼요.

## 7. 들어 있는 기능

- 휴대폰 화면을 먼저 생각한 반응형 디자인 (기본 = 휴대폰, 768px 이상 = 태블릿, 1024px 이상 = 데스크톱)
- 휴대폰: 햄버거 메뉴, 화면 아래 고정된 전화·예약 버튼, 휴대폰 전용 세로 배너 사진
- 휴대폰을 가로로 눕히면 하단 버튼을 숨겨서 화면을 넓게 써요
- 아이폰 노치(화면 윗부분 홈)와 홈 바 영역을 피해서 배치해요
